# Castrum

Castrum is a 2D game engine built in Go on-top of the brilliant [Ebiten](https://github.com/hajimehoshi/ebiten) library.

It provides a simple and efficient way to create 2D games with Go, leveraging the power of Ebiten for rendering and input handling.

Castrum aims to streamline the game development process by offering a set of tools and abstractions that make it easier to manage game states, entities, and resources.

## Planned Features

- **Entity Component System (ECS)**: A flexible architecture for managing game entities and their components.
- **Scene Management**: Tools for managing different game scenes and transitions between them.
- **Resource Management**: Efficient loading and management of game assets such as images, sounds, and fonts.
