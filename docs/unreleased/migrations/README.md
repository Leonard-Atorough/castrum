# Migrations

Migration notes describe the changes needed to move an existing game between
Castrum releases.

- [0.3.0 to unreleased](0.3.0-to-unreleased.md) - separate audio playback settings from clip and playlist selection, and move timers into the gametime package.
- [0.2.0 to 0.3.0](0.2.0-to-0.3.0.md) - store components by value and review the default system set.
- [0.1.0 to 0.2.0](0.1.0-to-0.2.0.md) - update camera setup and zoom handling.
