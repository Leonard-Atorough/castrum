## Suggested features

- **Entity namespacing**: A system for organizing and managing entities within different namespaces to avoid naming conflicts. Ties into the scene management system, allowing for better organization of game objects and their interactions.
- **Event System**: A robust event system that allows for communication between different parts of the game engine, enabling decoupled and modular design. This system will facilitate event-driven programming, making it easier to handle user input, game state changes, and other events.
