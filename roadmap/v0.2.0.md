# v0.2.0: Control and presentation

## Intent

Give games direct control over simulation time and strengthen the camera and
audio features that are already part of the engine's core 2D workflow.

## Feature set

### Game-level time control

- [ ] Add game-level pause/resume and time scaling without changing the
  fixed-timestep scheduler's deterministic contract.
- [ ] Define how pause and scale affect fixed updates, frame updates,
  animation, timers, and audio reconciliation. Keep wall-clock/platform
  behavior separate where it should continue during a paused simulation.
- [ ] Make the API explicit about when changes take effect and provide tests
  for pause, resume, scale changes, and slow-frame/spiral-guard interaction.

### Camera and transforms

- [ ] Add camera rotation and camera bounds, with documented coordinate
  conventions and predictable behavior at viewport edges.
- [ ] Verify transform interpolation for translation, rotation, and scale
  across wraparound/angle boundaries and document pixel-snap behavior.
- [ ] Keep camera behavior consistent with the current transform and
  rendering model; defer parent-child transform propagation.

### Audio

- [ ] Add basic pan control for the default audio path.
- [ ] Document and test the relationship between source state, mixer buses,
  pause, completion, and pan.

### Input contract

- [ ] Verify and document mouse-wheel action semantics, including
  frame-versus-tick reads and whether wheel values are impulses or held
  state.

## Release gates

- [ ] Provide runnable examples for pausing/scaling time and for camera
  rotation or bounds.
- [ ] Tests demonstrate that the new controls do not cause duplicate or
  skipped fixed updates beyond the documented scheduler behavior.
- [ ] Update guides, API docs, and performance measurements affected by the
  changes.

## Explicitly not in this target

Entity hierarchy, full UI, scene management, physics response, and
asynchronous/batch loading remain out of scope. They need separate lifecycle,
ownership, or performance designs rather than being bundled with time
controls.
