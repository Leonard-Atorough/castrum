# Unreleased documentation

This documentation tracks the in-development engine API after v0.3.0. The API and examples may change before release, and snippets that use new APIs will not compile against the v0.3.0 module.

When a version is released, copy this documentation to a versioned directory and keep that released copy stable. Update this directory for subsequent in-development changes.
