## [0.1.0-alpha] - TBD

### Added

- ECS foundation (entities, components, systems, queries)
- Fixed-timestep game loop (60 TPS default)
- Scene management with load/unload/transition lifecycle
- Rendering pipeline (sprites, primitives, layer-based sorting, single camera)
- Input handling (keyboard, mouse, gamepad normalization)
- Configuration management (YAML-based)
- Timer and animation systems
- Basic collision detection
- Asset loading (textures, images via filesystem)
- Debug overlay (FPS, TPS, camera info)
- Comprehensive test coverage

### Known Limitations

- Single camera only (multi-viewport support deferred)
- No persistence (save/load)
- No audio system
- No visual editor
- Performance profiling not included
